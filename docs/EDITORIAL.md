# Catálogo de notícias

O arquivo público dist/data/news.json contém apenas matérias publicadas. Nunca armazenar rascunhos, credenciais ou material de revisão nesse arquivo. O campo status organiza a exibição; não constitui controle de acesso nem sistema de aprovação. Uma edição do catálogo é publicada por commit após autorização editorial de Erico Mattos. A primeira notícia foi migrada do ZIP 0.8 integrado já autorizado. Nenhuma nova matéria foi gerada nesta etapa.

Próxima fase: área autenticada e armazenamento privado para propostas e revisões; somente exportar para o catálogo após aprovação persistida no servidor.
