# Central da Fiel — v0.8

Prévia privada no Sites, preservando a referência aprovada. Site estático em dist, sem build.

## Hospedagem
Sites e Vercel são independentes. Nenhum vínculo automático foi configurado. Na Vercel existente, selecionar o repositório oficial e usar dist como Output Directory, sem build command. Preservar o projeto e domínio atuais. Não realizar a troca antes da validação dos materiais.

## Estado
Navegação por hash, home responsiva, seções próprias e aviso de independência. Sem API, resultados, classificação ou notícias publicados. Imagens são recortes ilustrativos do mockup aprovado, para revisão privada; substituir por materiais autorizados antes de publicação pública.

## Editorial
Pauta → fontes verificadas → proposta → revisão por Erico Mattos → aprovação → publicação. Automação e painel editorial ainda não implementados. Aprovação deve ser validada no servidor em uma próxima fase, nunca apenas no frontend.
